# dev-almanac

<p align="center"><strong>程序员黄历 + 今日星运：给 Claude Code 加一点每日仪式感。</strong></p>

<p align="center"><sub>离线 · 确定性 · 不耗 token · 绝不打扰正事</sub></p>

一个 Claude Code mod，把黄历和每日星运放在你写代码的地方。传统宜忌翻译成编程活动：破土＝`git init`，开市＝发版上线，
嫁娶＝合并分支，祭祀＝写文档，解除＝删死代码，忌动土＝今天别改数据库表结构。

## 功能

- **输入框上方的一行卡片**：显示农历日期和你的星座星级，后面的滚动条轮流显示宜、忌、幸运物，以及今天的节日或星期小语。点 **详情** 展开；发出第一条消息后自动收起。
- **状态栏**：例如 `🀄 宜写文档 ☿ 水逆`。
- **`/almanac`**（或 `/huangli`）：完整黄历面板。
  - 一张季节明信片：落叶、雪、花瓣或夏风，旁边是带摆动拉绳的撕页台历。
  - 宜忌对照表：左边是黄历原词，右边是对应的编程活动。
  - 冲煞、节气，以及十二时辰（吉时会点亮）。
  - 十二星座运势（‹ › 切换）；填上 🎂 生日后会标出你自己的星座。
  - 一只可以摇的签筒。
- **`/qiuqian`**（或 `/fortune`）：从 100 支签（上上签 … 下下签）中求一支，附程序员签诗。不满意可以再摇一次，换一支。
- **中英切换**：点卡片或面板上的 🌐，或输入 `/almanac en` / `/almanac zh`，选择会被记住。
- **特别的日子**：春节、中秋等传统节日，1024 程序员节，每个节气开始的那天；大约每个农历月还有一个大吉之日，会显示金色卡片并弹出提示。

星运包括：
- 综合、编码、调试、评审星级
- 幸运色（同时给卡片描边）
- 幸运物
- 幸运数字（以 HTTP 状态码、端口或退出码呈现）
- 幸运语言或工具
- 幸运时辰（取自今日吉时）
- 最佳结对星座
- 贵人、小心事项和一句建议

水逆时调试减一星并提示；今日所冲恰好是你的生肖时，也会温柔提醒。

## 设计理念

这个 mod 是按下面这些原则做的，以后修改也请沿用。

**绝不打扰正事。** 没有任何 hook 会阻止、改写或拖慢你的输入和工具调用；任何部分出错，会话都照常进行。卡片在第一条消息后自动收起，`level` 可以把这些额外效果调低或关掉。

**离线、确定。** 一切只取决于日期和你的生日：不联网、不调用模型、不耗 token。同一天在任何机器上，黄历、星运和当天第一支签都一样。黄历用 lunar-javascript 计算，水逆日期取自公开的表。

**笑点在对照。** 宜忌保留黄历原词，旁边写编程含义（嫁娶 → 合并分支）。原词在左、颜色淡、宽度固定，像词典的词条。对照关系只放在一张表里（`hooks/almanac.ts`），意思相近的词归成一组：同组的两个词同一天出现（如祭祀、祈福），就合并成一行；只出现一个时，保留它自己更具体的说法。每边最多显示五条，其余收进「+N 更多」。

**幸运色依五行。** 色板共二十种中国传统色（竹青、朱砂、藤黄、月白、天青……），每种配一个程序员别名，每一行四种。
- **怎么选：** 先看当日纳音五行，再按「生我者吉」取能生它的那一行（水生木、木生火……）。每个星座从这一行的四种颜色里选一种，面板上会写明来由（如「金生水」）。
- **为什么都是中间色调：** 明度和饱和度相近，做边框或色块时，在浅色和深色主题里都看得清。
- **为什么不用紫色：** 下面提到的设计原则规定强调色不用紫色，因为它几乎成了千篇一律的生成式界面的标配；紫色放在黄历暖色系的朱砂、藤黄、竹青旁边，也会很突兀。

**平涂、安静、清楚。** 插画遵循 [design-taste-frontend](https://github.com/Leonxlnx/taste-skill) 中适用于小插画的部分：
- 只用平涂色，不用渐变和模糊阴影
- 圆角统一用一套尺寸，嵌套层级保持浅
- 文字对比度不低于 4.5:1
- 按钮直接写明作用（🌐 English、修改生日）
- 不重复内容：面板外框已有标题，农历日期已印在明信片上

**动效有始有终。** 每个动画只播一次，大约五秒内停下：
- 落叶、雪、花瓣飘摆着落到山坡线上停住，所以静止的画面就是这些落定的叶子。
- 拉绳摆几下，再轻晃一次后停住。
- 签筒先晃一下示意可以摇；摇的时候签筒左右摆、签子乱跳，抽中的那支带着签号滑出来。
- 系统开了"减少动态效果"时，所有动画停止，内容也不会被藏起来。
- 图形用 SVG 内的 CSS 动画，动画进行中不会被重绘；终端里则用文字逐帧表现（飘动的落叶、抖动的签筒）。

**设置就在用的地方。** 生日直接在星运框的 🎂 输入框里填（或用 `/almanac birthday …`），不用去设置菜单找；语言一键切换。两者都会跨会话记住。

**只为好玩。** 每个面板都写着：仅供娱乐，代码质量还得靠测试。

## 安装

在终端会话的输入框中：

```
/plugin install dev-almanac --marketplace BruceXcluding/dev-almanac
```

按 `y` 添加 marketplace，再选择安装范围。在 shell 中：

```bash
claude plugin install dev-almanac --marketplace BruceXcluding/dev-almanac
```

在桌面应用中（不支持 `/plugin`）：点输入框旁的 +，选 Plugins，用 `BruceXcluding/dev-almanac` 添加 marketplace，再添加插件。

## 设置

**生日：** 在 `/almanac` 面板的 🎂 输入框里填写，或输入 `/almanac birthday 1997-06-01`（`/almanac birthday clear` 清除）。只保存在本机。

默认值也可以通过插件选项设置（`dev-almanac.birthday`、`dev-almanac.language`、`dev-almanac.level`）：

| 设置 | 取值 | 默认 |
| --- | --- | --- |
| `birthday` | `YYYY-MM-DD`：用于星座和生肖 | 空 |
| `language` | `zh`、`en` | `zh` |
| `level` | `lively`（卡片、状态栏、提示、动画）、`quiet`（仅状态栏，不播开场动画）、`off`（仅命令） | `lively` |
